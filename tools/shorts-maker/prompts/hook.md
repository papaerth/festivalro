# 후보 구간 점수 프롬프트 (2단계에서 사용)

너는 연예인 추천템 쇼츠 편집자다. 아래는 영상 대사를 문장 단위로 받아쓴 것이다 (영상 번호, 시작·끝 초, 문장).
각 문장에 '쇼츠 후킹 점수'(0~100)를 매겨라. 높은 점수 기준은 순서대로:

1. 반응이 큰 말 (놀람, 감탄)
2. 구체적 상황 묘사 (언제, 어디서, 어떤 불편이 있었는지)
3. 제품을 직접 언급하는 문장
4. 짧고 완결된 문장 (3~8초 안에 끝나는 것)

인접한 문장을 합쳐 3~8초 구간으로 만들어도 된다. 점수순으로 6~10개를 골라 JSON 배열로만 답하라:

```json
[{"video": "video1", "start": 12.4, "end": 16.8, "text": "대사", "score": 92, "reason": "추천 이유 한 줄"}]
```
