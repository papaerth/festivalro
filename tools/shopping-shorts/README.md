# 쇼핑 쇼츠 자동 제작

원본 영상 하나를 넣으면 연예인 추천템 쇼핑 쇼츠 한 편의 완성본 여섯 가지를 만든다.

| 만들어지는 것 | 파일 |
|---|---|
| 배경음악 있는 버전 | `<제품명>_배경음O.mp4` |
| 배경음악 뺀 버전 | `<제품명>_배경음X.mp4` |
| 썸네일 | `<제품명>_썸네일.jpg` |
| 제목(1순위 + 대안 2) · 설명 · 핀 댓글 | `<제품명>_업로드문구.txt` |
| 사람이 확인할 것 · 차순위 제품 후보 | `<제품명>_보고.txt` |

제작 규칙은 [`RULES.md`](RULES.md) 한 곳에 있다. 규칙을 바꾸려면 그 파일을 고친다.

## 흐름

```
원본 영상 ─ 음성 인식(어절별 시각) ─┐
유튜브 링크 ─ 댓글 ────────────────┼─ 분석·제품 선정 ─ 컷 설계·문구 ─ 규칙 검사 ─ TTS ─ 렌더링 ─ 검수 ─ 업로드 문구·보고
프레임 시트 ───────────────────────┘      (Claude)        (Claude)     (자동 재설계)                (재인식·화면 확인)
```

- 판단이 필요한 단계(제품 선정, 컷 설계, 문구, 화면 검수)는 Claude가, 나머지는 스크립트가 한다.
- 컷 설계는 규칙 검사기를 통과할 때까지 자동으로 다시 한다(20초, 순서 섞기, 구간 겹침, TTS 18자, 제목 금지어, 업로드 제목 20자 이내, 유튜브 정책에 걸리기 쉬운 표현(몇 kg 빠졌다는 수치, 단식·굶기 등), 크롭 범위, 자막이 음성 인식과 같은지).
- 컷 안의 쉼(0.3초 이상)은 무음 감지로 찾아 자동으로 잘라낸다.
- 렌더 뒤에는 완성본 음성을 다시 인식해 자막 싱크를 대조하고, TTS 구간에 원본 소리가 섞이지 않았는지 확인한다.

## 설치 (Windows)

1. [Python 3.10 이상](https://www.python.org/downloads/windows/)과 [ffmpeg](https://www.gyan.dev/ffmpeg/builds/)를 설치하고 PATH에 넣는다.
2. 이 폴더에서:

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy env.example .env
```

3. `.env`를 열어 키를 넣는다.
   - `ANTHROPIC_API_KEY` — 전체 자동 실행에 필요 (https://console.anthropic.com)
   - `ELEVENLABS_API_KEY` — TTS. 계정의 `kanna - Calm & Friendly` 목소리를 이름으로 찾는다.
4. 한글 폰트: Noto Sans KR(Black, Regular)을 설치하면 그것을, 없으면 맑은 고딕을 쓴다.

음성 인식·무음 감지·배경음 제거 모델(약 400MB)은 처음 실행할 때 `models/`로 자동으로 내려받는다.

## 창으로 쓰기 (바탕화면 아이콘)

```bat
python gui.py --shortcut
```

바탕화면에 `쇼츠 만들기` 아이콘이 생긴다. 더블클릭하면 창이 열리고, 영상 파일을 아이콘 위에 끌어다 놓아도 된다.

창은 위에서 아래로 **① 영상 넣기 → ② 만들기 → ③ 결과** 순서다.

1. **① 영상 넣기**: **파일 고르기**로 원본 영상을 고르고, 유튜브 링크를 복사한 뒤 **붙여넣기**를 누른다.
   인포크 번호와 제품명(정했을 때만)은 있으면 적는다. 편 이름·인포크 링크·TTS 이미지·vidIQ 분석은 **추가 설정**을 누르면 나온다
   (편 이름은 비워 두면 파일 이름으로 정해진다).
   **인포크 링크**에 내 인포크 주소(예: `link.inpock.co.kr/아이디`)를 한 번 적어 두면, 그 뒤 모든 영상의 설명에서
   인포크 번호 줄 바로 아래에 `➡️ 주소`로 들어간다. 이 칸은 **모두 지우기**를 눌러도 지워지지 않는다.
2. **② 만들기**: **▶ 만들기**를 누른다. 영상을 편 폴더에 복사하고 끝까지 만든다. 여섯 단계(대사 읽기 → 제품 선정 → 컷 설계 →
   음성·댓글 → 영상 만들기 → 검수·문구) 중 어디까지 왔는지 동그라미로 보이고, 그 아래에 지금 하는 일이 한 줄로 나온다.
   만드는 동안 입력 칸은 접힌다(**입력 칸 펼치기**로 다시 연다).
3. **③ 결과**: 끝나면 결과가 나오고, **결과 폴더 열기**로 영상을 본다.

- 창을 닫았다 다시 열면 마지막에 하던 작업이 결과·업로드 문구·진행 기록과 함께 그대로 열린다.
- **이전 작업 보기**: 지금까지 만든 편의 목록(제품, 상태, 마지막 작업 시각)에서 골라 다시 연다.
- **모두 지우기 (새 영상)**: 창의 모든 칸과 결과·기록 화면을 비운다. 만든 파일은 지우지 않으며 이전 작업 목록에 남는다.
  지운 뒤에 넣는 영상은 **늘 새 작업**으로 처음부터 만든다. 영상 파일 이름이 이전 작업과 같아도 이전 작업의 분석·컷 설계·두 번째 영상을
  물려받지 않고, 편 이름 뒤에 `_2`, `_3` … 을 붙여 따로 만든다. 이전 작업을 이어서 하려면 **이전 작업 보기**에서 연다.
- 이전 작업을 연 채로 다른 영상을 넣고 **만들기**를 누르면 새 작업으로 만들지 물어본다.
- 중간에 멈췄으면 그대로 **만들기**를 누르면 이어서 한다.
- 제품을 바꾸려면 제품명을 적고 다시 **만들기**(제품 선정부터 자동으로 다시 한다). 컷만 다시 짜려면 왼쪽 목록에서 `컷 설계부터 다시`.

**영상 2개를 섞어 만들기**: 같은 제품을 다룬 영상이 둘 있으면 **영상 2** 칸에 두 번째 영상을, **영상 2 링크** 칸에 그 영상의
유튜브 링크를 넣고 **만들기**를 누른다(두 칸은 **＋ 같은 제품의 영상 하나 더 섞기**를 누르면 나온다). 두 영상에서 그 제품이 나오는 장면만 골라 번갈아 섞고, 출처는 그때 화면에 나오는 영상의 채널만 적는다.
댓글 카드는 두 영상의 댓글에서 고른다. 결과의 "장면 구성"에 장면마다 영상 A·B 중 어디서 왔는지 나온다.
- 영상 둘을 한꺼번에 아이콘 위에 끌어다 놓아도 된다.
- 이미 만든 편에 두 번째 영상을 더하면 제품 선정부터 다시 해서 새 버전으로 만든다.
- 한쪽 영상에 그 제품이 안 나오면 그 영상은 쓰지 않고, 결과의 "사람이 확인할 것"에 적는다.
- 영상 2 칸을 비워 두면 지금까지처럼 영상 하나로 만든다.

③ 결과는 탭 네 개(결과 · 업로드 문구 · 진행 기록 · 작업 목록)이고, 오른쪽에서 **버전**을 고른다.

- **버전**: 다시 만들 때마다 `output/<편>/01_처음`, `02_수정`, `03_제품변경` … 처럼 새 폴더에 만든다. 이전 완성본은 지워지지 않는다.
  목록에서 버전을 고르면 그 버전의 결과와 문구가 보이고, **결과 폴더 열기**로 그 버전의 영상을 본다.
- **결과**: 사람이 확인할 것, 수정 요청이 어떻게 반영됐는지, 차순위 제품 후보.
  - **차순위 후보로 다시 만들기**: 제품 태그 검색이 안 될 때 후보 버튼을 누르면 그 제품으로 다시 만든다.
  - **수정 요청**: 고치고 싶은 점을 적고 **수정본 만들기**(또는 Ctrl+Enter)를 누르면 이전 설계를 바탕으로 그 부분만 고친 수정본을 새 버전으로 만든다
    (예: 첫 장면을 바르는 장면으로 / 제목을 더 짧게 / 댓글 카드는 아래쪽에). 요청은 `input/<편>/feedback.txt`에 남는다.
- **업로드 문구**: 제목 3개, 설명, 핀 댓글마다 **복사** 버튼이 있다. 누르고 유튜브 업로드 화면에 붙여 넣는다.
- **진행 기록**: 단계별 진행 상황. 오류는 빨간 줄로 나온다.
- **작업 목록**: 여러 편을 동시에 만든다. **만들기**를 누른 뒤 **모두 지우기**로 다음 영상을 넣고 또 **만들기**를 누르면 함께 진행된다.
  동시에 만들 개수(기본 3, 최대 4. 이 탭에서 바꾼다)를 넘으면 차례를 기다렸다가 자동으로 시작한다. 줄을 두 번 누르면 그 작업이 열린다.
  편마다 끝날 때 알림이 뜬다. PC가 느려지면 개수를 줄인다.

끝나거나 멈추면 창이 앞으로 나오며 알림이 뜬다. 완료 알림에서 "예"를 누르면 그 버전 폴더가 열린다.

### 미리보기 · 글자체
**미리보기 · 글자체** 버튼을 누르면 창이 하나 더 열린다. 설정은 탭 네 개(글자체 · 자막 변화 · 앱 화면 · 음악)로 나뉜다.

- **글자체**: 썸네일 문구(화면 상단 제목)와 자막의 글자체와 크기를 따로 고른다. PC에 설치된 글자체 중 한글이 되는 것만 목록에 나온다.
  **굵게**를 켜면 어떤 글자체든 획을 조금 더 두껍게 그린다.
- **글자체 더 넣기** (글자체 탭 아래쪽)
  - **추천 무료 글자체 받기**: 구글 폰트의 무료 한글 글자체 12종(Black Han Sans, Do Hyeon, Jua, Bagel Fat One, Gasoek One, 나눔 손글씨 등,
    약 20MB)을 한 번에 받는다. 상업적으로 써도 되는 글자체(SIL Open Font License)다.
  - 다른 글자체는 파일(.ttf .otf)을 받아 **글자체 폴더 열기**로 열리는 `fonts` 폴더에 넣거나 윈도우에 설치한 뒤 **목록 새로 고침**을 누른다.
    무료 글자체는 눈누(noonnu.cc)에 많다. 글자체마다 사용 범위(영상·상업용)가 다르니 확인하고 쓴다.
- **자막 변화**: 자막이 단조롭지 않게 변화를 준다.
  - **강조할 말을 크게 · 다른 색 · 다른 글자체로**: AI가 자막마다 힘줄 낱말(화자가 힘준 말, 효과, 숫자, 제품명)을 고르면 그 낱말만
    크게, 색 있게, **강조 글자체**로 나온다. 크기(%)와 강조 색(노랑·민트·분홍 번갈아 / 노랑만)을 고를 수 있다.
  - **자막이 뜰 때 움직임**: 톡 튀어나오기 / 아래에서 올라오기 / 없음. 움직임은 완성 영상에서 보인다.
  - 이미 만든 편에 강조 낱말을 넣으려면 본 창에서 `컷 설계부터 다시`로 만든다(글자체·색·움직임만 바꿀 때는 `렌더링만 다시`).
- **배경 음악**: 음악 파일(mp3 등)을 고르면 목소리만 있는 버전 밑에 깔아 `<제품명>_음악.mp4`를 하나 더 만든다. 영상보다 짧으면 반복하고,
  앞뒤는 부드럽게 줄인다. 크기는 목소리 대비 비율로 정한다. **유튜브 오디오 보관함 열기**로 무료 음악을 받을 수 있다.
  유튜브 앱 업로드 화면의 "사운드 추가"는 앱에서 직접 해야 한다(그때는 `배경음X` 파일을 올린다).
- **볼 장면**: 썸네일이나 자막이 뜬 장면을 골라 본다. 원본 글씨를 지웠거나 거울반전을 푼 컷도 실제대로 보인다. 댓글 카드도 함께 볼 수 있다. 실제 렌더링과 같은 그리기 코드를 쓴다.
- **앱에서 보이는 모습**: YouTube Shorts, TikTok, Instagram 릴스의 버튼과 글자가 놓이는 자리를 덧그려, 제목·자막·카드가 가려지는지 본다.
  실제 앱 화면을 그대로 옮긴 것은 아니고 자리를 비슷하게 흉내 낸 것이다.
- **저장**: 다음에 만드는 영상부터 적용된다(`settings.json`). **저장하고 이 편을 다시 렌더링**은 지금 편을 새 버전으로 다시 만든다.

### vidIQ와 함께 쓰기
vidIQ는 Claude 앱에 연결된 도구라 이 프로그램이 직접 부르지는 못한다. 대신 분석 결과를 붙여 넣으면 제품 선정과 후킹 장면 판단에 함께 쓴다.

1. 창에서 유튜브 링크를 넣고 **vidIQ 질문 복사**를 누른다.
2. vidIQ가 연결된 Claude 앱에 붙여 넣어 답을 받는다.
3. 그 답을 창의 **vidIQ 분석 붙여 넣기** 칸에 붙여 넣고 **만들기**.

명령줄에서는 같은 글을 `input/<편>/vidiq.txt`로 저장하면 된다.

## 명령줄로 쓰기

```bat
python shorts.py new 이사배_피지오겔 --url https://youtu.be/XXXXXXXXXXX --inpock 123
```

`input\이사배_피지오겔\` 폴더가 생긴다. 여기에 원본 영상(mp4)을 넣는다. TTS 구간에 쓸 이미지가 있으면 `img1.jpg`, `img2.jpg`로 넣는다.

```bat
python shorts.py auto 이사배_피지오겔
```

끝나면 `output\이사배_피지오겔\`에 완성본이 있다. 여러 편을 한꺼번에 하려면 폴더들을 만들어 두고 `run.bat`을 더블클릭한다(`auto --all`).

- 영상 2개를 섞으려면 `new`에 `--url2 <둘째 링크>`를 더하고 폴더에 영상을 둘 넣는다(이름순으로 첫째가 A).
  순서를 정하려면 `info.json`에 `"videos": ["첫영상.mp4", "둘째영상.mp4"]`.
- 제품을 직접 정하려면 `--product "피지오겔 DMT 크림"`. 없으면 규칙에 따라 고르고 차순위 후보 2개를 보고에 적는다.
- 결과가 마음에 안 들면 `work\<편>\plan.json`(컷·자막·제목)을 고친 뒤 `python shorts.py render <편>` → `qa <편>`.
- 제품을 바꾸려면 `info.json`의 `product`를 고치고 `python shorts.py auto <편> --redo analyze`.
- 컷 설계만 다시: `--redo design`.

### API 키 없이 쓰기 (Claude Code)
Claude Code에서 `/shorts <편이름>` 을 실행하면 Claude가 판단 단계를 직접 하고 같은 스크립트로 렌더링한다. 순서는 [`CLAUDE.md`](CLAUDE.md).

## 인물을 화면 가운데로
컷마다 얼굴을 찾아, 인물이 1:1 화면의 가로 정중앙에 오도록 자르는 위치를 자동으로 맞춘다(썸네일과 정지 화면도).
얼굴이 안 보이는 제품 클로즈업은 설계 값 그대로 둔다. 비슷한 크기의 두 사람이 함께 잡히면 둘 사이를 가운데로 한다.
특정 컷을 맞추지 않으려면 plan의 그 컷에 `"center": false`.

## 원본 영상의 글씨
원본에 박힌 자막·라벨·제품의 큰 글씨는 이 순서로 처리한다(규칙은 `RULES.md`).

1. 글씨가 안 보이는 컷을 고르고 크롭 위치를 옮겨 피한다.
2. 작고 단순한 배경 위의 글씨는 주변 색으로 메워 지운다(plan의 `erase`).
3. 지울 수 없으면 그 컷만 거울반전을 풀어 글씨가 바로 읽히게 한다(컷의 `"mirror": false`).

렌더 뒤 화면 검수에서 뒤집힌 글씨가 보이면 자동으로 크롭을 옮기거나 그 컷의 반전을 푼다.
수정 요청에 "3번째 장면 글씨 지워줘", "제품 클로즈업은 반전 풀어줘"처럼 적어도 된다.

## 사람이 해야 하는 일
- 유튜브 업로드 화면에서 **제품 태그 검색이 되는지** 확인. 안 되면 보고의 차순위 후보로 다시 만든다.
- 인포크 번호 만들기, 업로드.
- **배경음X 버전**을 한 번 들어 보기(배경음 제거가 목소리를 뭉개는 경우가 있다).
- 원본 영상 파일 준비. 이 프로그램은 유튜브에서 영상을 내려받지 않는다.

## 알아둘 것
- 거울반전·1.1배속·크롭을 해도 저작권 신고나 재사용 콘텐츠 판정을 피할 수 있는 건 아니다. 원본 채널의 허락 범위 안에서 쓴다.
- 댓글 카드는 영상 바로 아래에 화면 폭의 흰 띠로 붙고, 그 아래에 출처 문구가 온다(영상 속 인물·제품·자막을 가리지 않는다).
  고른 제품과 관련 있고 센스 있는 댓글(사용감·효과·공감·재치)을 고른다. 글자 수 제한은 없다.
  표시 시간은 댓글 길이로 정하며 다 읽기에 살짝 모자라게 한다(약 2~5초).
- 댓글 카드는 실제 유튜브 댓글창을 캡처한 그림 그대로다. PC의 Edge(없으면 Chrome)를 화면 없이 띄워 영상의 댓글창에서 고른 댓글을
  프로필·아이디·댓글 글까지 찍고(좋아요·답글 줄은 뺀다), 프로필 사진과 핸들(아이디)만 흐리게(블러) 처리한다. 이모지도 그대로 나온다.
  화면 없는 방식으로 댓글창이 안 열리면 브라우저 창을 잠깐 띄워 다시 한다. 그래도 안 되면 `work/<편>/capture_debug.png`에
  그때 보인 화면을 남기고, 그린 댓글 상자로 대신한다. 캡처하지 못하면(브라우저 없음, 댓글을 못 찾음) 프로그램이 그린 댓글 상자를 대신 쓰고 결과의 확인할 것에 적는다.
  끄려면 `.env`에 `SHORTS_CAPTURE=0`.
- 컷이 바뀔 때의 '휙' 소리는 넣지 않는다. 효과음은 팁 시작·핵심 멘트·제품 공개 때만 쓴다. 이모지는 폰트에 없어 빠진다(보고에 적힌다).
- 한 편에 Claude API를 서너 번 호출한다(프레임 시트 이미지 포함). 모델은 `.env`의 `SHORTS_MODEL`로 바꿀 수 있다.
- 음성 인식(sherpa-onnx 한국어 모델)은 고유명사·제품명을 틀리게 적을 수 있다. 컷 설계 단계에서 문맥으로 바로잡지만, 자막은 한 번 훑어보는 편이 좋다.
- 댓글을 못 가져오면(링크 없음, 차단) 댓글 카드 없이 만들고 보고에 적는다. `input/<편>/comments.json`으로 직접 줄 수 있다.
