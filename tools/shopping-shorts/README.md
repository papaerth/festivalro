# 쇼핑 쇼츠 자동 제작

원본 영상 하나를 넣으면 연예인 추천템 쇼핑 쇼츠 한 편의 완성본 여섯 가지를 만든다.

| 만들어지는 것 | 파일 |
|---|---|
| 배경음악 있는 버전 | `<제품명>_배경음O.mp4` |
| 배경음악 뺀 버전 | `<제품명>_배경음X.mp4` |
| 썸네일 | `<제품명>_썸네일.jpg` |
| 제목(1순위 + 대안 2) · 설명 · 핀 댓글 | `<제품명>_업로드문구.txt` |
| 사람이 확인할 것 · 차순위 제품 후보 | `<제품명>_보고.txt` |

제작 규칙은 [`RULES.md`](RULES.md) 한 곳에 있다. 규칙을 바꾸려면 그 파일을 고친다.

## 흐름

```
원본 영상 ─ 음성 인식(어절별 시각) ─┐
유튜브 링크 ─ 댓글 ────────────────┼─ 분석·제품 선정 ─ 컷 설계·문구 ─ 규칙 검사 ─ TTS ─ 렌더링 ─ 검수 ─ 업로드 문구·보고
프레임 시트 ───────────────────────┘      (Claude)        (Claude)     (자동 재설계)                (재인식·화면 확인)
```

- 판단이 필요한 단계(제품 선정, 컷 설계, 문구, 화면 검수)는 Claude가, 나머지는 스크립트가 한다.
- 컷 설계는 규칙 검사기를 통과할 때까지 자동으로 다시 한다(20초, 순서 섞기, 구간 겹침, TTS 18자, 제목 금지어, 크롭 범위, 자막이 음성 인식과 같은지).
- 컷 안의 쉼(0.3초 이상)은 무음 감지로 찾아 자동으로 잘라낸다.
- 렌더 뒤에는 완성본 음성을 다시 인식해 자막 싱크를 대조하고, TTS 구간에 원본 소리가 섞이지 않았는지 확인한다.

## 설치 (Windows)

1. [Python 3.10 이상](https://www.python.org/downloads/windows/)과 [ffmpeg](https://www.gyan.dev/ffmpeg/builds/)를 설치하고 PATH에 넣는다.
2. 이 폴더에서:

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy env.example .env
```

3. `.env`를 열어 키를 넣는다.
   - `ANTHROPIC_API_KEY` — 전체 자동 실행에 필요 (https://console.anthropic.com)
   - `ELEVENLABS_API_KEY` — TTS. 계정의 `kanna - Calm & Friendly` 목소리를 이름으로 찾는다.
4. 한글 폰트: Noto Sans KR(Black, Regular)을 설치하면 그것을, 없으면 맑은 고딕을 쓴다.

음성 인식·무음 감지·배경음 제거 모델(약 400MB)은 처음 실행할 때 `models/`로 자동으로 내려받는다.

## 창으로 쓰기 (바탕화면 아이콘)

```bat
python gui.py --shortcut
```

바탕화면에 `쇼츠 만들기` 아이콘이 생긴다. 더블클릭하면 창이 열리고, 영상 파일을 아이콘 위에 끌어다 놓아도 된다.

1. **파일 고르기**로 원본 영상을 고르고 유튜브 링크를 붙여 넣는다. 편 이름은 파일 이름으로 자동으로 채워진다.
2. 인포크 번호, 제품명(정했을 때만), TTS 이미지는 있으면 넣는다.
3. **만들기**를 누른다. 영상을 편 폴더에 복사하고 끝까지 만든다. 진행 상황이 아래 기록 칸에 나온다.
4. 끝나면 **결과 폴더 열기**.

- 만들던 편은 편 이름 목록에서 다시 고를 수 있다. 중간에 멈췄으면 그대로 **만들기**를 누르면 이어서 한다.
- 제품을 바꾸려면 제품명을 적고 다시 **만들기**(제품 선정부터 자동으로 다시 한다). 컷만 다시 짜려면 왼쪽 목록에서 `컷 설계부터 다시`.

아래쪽은 두 장이다.

- **결과**: 사람이 확인할 것, 수정 요청이 어떻게 반영됐는지, 차순위 제품 후보, 제목과 썸네일 문구.
  - **차순위 후보로 다시 만들기**: 제품 태그 검색이 안 될 때 후보 버튼을 누르면 그 제품으로 다시 만든다.
  - **수정 요청**: 고치고 싶은 점을 적고 버튼을 누르면 이전 설계를 바탕으로 그 부분만 고쳐 다시 만든다
    (예: 첫 장면을 바르는 장면으로 / 제목을 더 짧게 / 댓글 카드는 아래쪽에). 요청은 `input/<편>/feedback.txt`에 남는다.
- **진행 기록**: 단계별 진행 상황. 오류는 빨간 줄로 나온다.
- **프로그램 업데이트**는 GitHub의 최신 파일을 받아 덮어쓴다. 키와 만든 편은 그대로 둔다.

### vidIQ와 함께 쓰기
vidIQ는 Claude 앱에 연결된 도구라 이 프로그램이 직접 부르지는 못한다. 대신 분석 결과를 붙여 넣으면 제품 선정과 후킹 장면 판단에 함께 쓴다.

1. 창에서 유튜브 링크를 넣고 **vidIQ 질문 복사**를 누른다.
2. vidIQ가 연결된 Claude 앱에 붙여 넣어 답을 받는다.
3. 그 답을 창의 **vidIQ 분석 붙여 넣기** 칸에 붙여 넣고 **만들기**.

명령줄에서는 같은 글을 `input/<편>/vidiq.txt`로 저장하면 된다.

## 명령줄로 쓰기

```bat
python shorts.py new 이사배_피지오겔 --url https://youtu.be/XXXXXXXXXXX --inpock 123
```

`input\이사배_피지오겔\` 폴더가 생긴다. 여기에 원본 영상(mp4)을 넣는다. TTS 구간에 쓸 이미지가 있으면 `img1.jpg`, `img2.jpg`로 넣는다.

```bat
python shorts.py auto 이사배_피지오겔
```

끝나면 `output\이사배_피지오겔\`에 완성본이 있다. 여러 편을 한꺼번에 하려면 폴더들을 만들어 두고 `run.bat`을 더블클릭한다(`auto --all`).

- 제품을 직접 정하려면 `--product "피지오겔 DMT 크림"`. 없으면 규칙에 따라 고르고 차순위 후보 2개를 보고에 적는다.
- 결과가 마음에 안 들면 `work\<편>\plan.json`(컷·자막·제목)을 고친 뒤 `python shorts.py render <편>` → `qa <편>`.
- 제품을 바꾸려면 `info.json`의 `product`를 고치고 `python shorts.py auto <편> --redo analyze`.
- 컷 설계만 다시: `--redo design`.

### API 키 없이 쓰기 (Claude Code)
Claude Code에서 `/shorts <편이름>` 을 실행하면 Claude가 판단 단계를 직접 하고 같은 스크립트로 렌더링한다. 순서는 [`CLAUDE.md`](CLAUDE.md).

## 사람이 해야 하는 일
- 유튜브 업로드 화면에서 **제품 태그 검색이 되는지** 확인. 안 되면 보고의 차순위 후보로 다시 만든다.
- 인포크 번호 만들기, 업로드.
- **배경음X 버전**을 한 번 들어 보기(배경음 제거가 목소리를 뭉개는 경우가 있다).
- 원본 영상 파일 준비. 이 프로그램은 유튜브에서 영상을 내려받지 않는다.

## 알아둘 것
- 거울반전·1.1배속·크롭을 해도 저작권 신고나 재사용 콘텐츠 판정을 피할 수 있는 건 아니다. 원본 채널의 허락 범위 안에서 쓴다.
- 댓글 카드의 프로필 사진과 이름은 모자이크하고, 작성자 이름은 저장하지 않는다. 이모지는 폰트에 없어 빠진다(보고에 적힌다).
- 한 편에 Claude API를 서너 번 호출한다(프레임 시트 이미지 포함). 모델은 `.env`의 `SHORTS_MODEL`로 바꿀 수 있다.
- 음성 인식(sherpa-onnx 한국어 모델)은 고유명사·제품명을 틀리게 적을 수 있다. 컷 설계 단계에서 문맥으로 바로잡지만, 자막은 한 번 훑어보는 편이 좋다.
- 댓글을 못 가져오면(링크 없음, 차단) 댓글 카드 없이 만들고 보고에 적는다. `input/<편>/comments.json`으로 직접 줄 수 있다.
