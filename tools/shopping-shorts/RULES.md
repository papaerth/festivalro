# 쇼핑 쇼츠 제작 규칙

연예인 추천템 유튜브 쇼핑 쇼츠(타겟 20~40대 여성)를 원본 영상 하나로 만든다.
사용자와 한 편(이사배 × 피지오겔 DMT 크림)을 같이 만들며 확정한 규칙이다.
이 파일은 사람(Claude Code)과 자동 실행(`shorts.py auto`의 Claude API 호출)이 함께 읽는 단 하나의 기준이다.
규칙을 바꾸려면 이 파일을 고친다.

## 1. 제품 선정 ("황금 소재 발굴")
항상 시청자 입장에서 판단한다. 분석 결과(대사·화면·댓글)를 근거로 한다.
- 쿠팡에서 팔고 유튜브 제품 태그를 달 수 있을 제품일 것
- 초반 3초 후킹 장면이 그 제품 구간 안에 있을 것 (궁금하게 / 시청자와 관련되게)
- 끝까지 보게 만드는 실용 팁이나 반전이 있을 것
- 화장품·미용·의류·액세서리 등 여성 용품 위주
- 제품을 고르면 차순위 후보 2개를 반드시 같이 낸다. 제품 태그 검색이 안 되면 그 제품은 버려야 하기 때문이다
  (실제로 후킹 1위였던 제품을 태그 검색이 안 돼서 버린 적이 있다).
- 사용자가 제품명을 주었으면 그 제품으로 한다.

## 2. 컷 설계
- 완성 길이 20초 이내 (1.1배속 적용 후, TTS 포함). 여유를 두고 17~19.5초를 노린다.
- 모든 컷과 정지 화면은 고른 제품이 화면에 나오거나 화자가 그 제품을 이야기하는 장면이어야 한다.
  다른 제품·다른 주제의 장면은 아무리 눈길을 끌어도 넣지 않는다(트리 바스켓 영상에 쿠키 장면이 들어가 지적받았다).
  쓸 장면이 모자라면 길이를 줄인다. 20초를 채우려고 무관한 장면을 넣지 않는다.
- 가장 후킹되는 장면을 맨 앞에(그 제품의 장면 중에서). 맨 앞은 컷이다(TTS로 시작하지 않는다).
- 시간순으로 놓지 않는다. 장면 순서를 2~3번 섞는다.
- 같은 소스 구간을 두 번 쓰지 않는다 (정지 화면도 다른 컷과 겹치지 않는 시각에서).
- 무음 구간은 반드시 잘라낸다. 문장 사이 쉼(0.3초 이상)도 컷으로 나눠 뺀다.
- TTS 2개, 각 18자 이내(공백 제외). 원본에서 말하지 않은 정보나 궁금증을 더하는 문구로.
  TTS 구간에는 이미지(사용자가 준 것) 또는 원본의 정지 화면을 깐다.
- 마지막 컷은 제품명이 나오는 장면으로 끝내면 처음 후킹으로 자연스럽게 이어진다(루프).
- 유명인 사진은 웹에서 내려받아 넣지 않는다. 사용자가 준 이미지나 원본 영상의 정지 화면만 쓴다.

크롭 (원본이 1920×1080일 때)
- 1:1 크롭은 위쪽 840×840만 쓴다(y0=0). 원본 화면 아래에 박힌 자막이 y≈880 아래에 있어서,
  전체 높이를 쓰면 거울반전 때 글자가 뒤집혀 보인다.
- x0는 컷마다 인물과 제품이 들어오게 정한다. 화면 위쪽 모서리의 브랜드 라벨·유료광고 고지 문구 같은
  글자가 크롭에 들어오지 않게 한다 (피지오겔 편에서는 x<130, x>1180 부근이었다. 영상마다 다르니 프레임에서 확인한다).

원본 영상의 글씨 (자막, 브랜드 라벨, 광고 고지, 제품의 큰 글씨, 간판)
1. 먼저 피한다. 글씨가 안 보이는 컷을 고르고, x0를 옮겨 크롭 밖으로 내보낸다. 이것이 가장 좋다.
2. 피할 수 없고 깔끔하게 지울 수 있으면 지운다(`erase`). 글씨가 작고, 단순한 배경(벽, 단색, 흐린 배경) 위에 있고,
   얼굴·손·제품을 가리지 않을 때만. 지운 자리는 주변 색으로 메워져서, 복잡한 배경이나 큰 글씨에서는 얼룩이 남는다.
3. 지울 수 없으면 그 컷만 거울반전을 푼다(`mirror: false`). 뒤집힌 글씨가 화면에 남는 것보다 낫다.
   화면 전체에 계속 떠 있는 글씨 때문에 거의 모든 컷이 해당되면 전부 풀어도 된다.
- 제품 이름이 보이는 클로즈업은 제품 공개 장면으로 가치가 있으니, 버리지 말고 3번(반전 풀기)으로 쓴다.

## 3. 자막 — 반드시 음성 인식으로
가장 크게 틀렸던 부분이다. 원본 화면에 박힌 자막은 요약·연출용이라 실제 말과 다르다
(예: 화면 "들뜬 베이스를 살짝 닦아내기" ↔ 실제 "그 건조한 부분을 이렇게 닦아내요").
글자 수 비율로 시간을 나누는 것도 안 된다. 싱크가 어긋난다.
- 음성 인식 결과(어절별 시작 시각)의 실제 문구로 자막을 쓴다. 인식이 명백히 틀린 글자(동음 오인식, 띄어쓰기)는
  문맥에 맞게 바로잡되, 말하지 않은 내용을 넣지 않는다.
- 컷의 시작·끝(a, b)도 어절 시각에 맞춘다. 시작은 첫 어절 시각보다 0.05초쯤 앞, 끝은 말이 끝난 뒤.
  말이 잘리지 않게, 불필요한 "그래서/그니까"는 뺀다.
- 자막은 두 어절씩 묶는다. 한 어절씩은 읽기 어렵다는 피드백을 받았다. 힘을 줄 말("없어요!", 제품명)만 혼자 띄운다.
- `subs[].t`는 그 묶음 첫 어절의 시작 시각(원본 초)이다.
- 자막 모양(크기 66, 흰색·검은 테두리, 강조는 노란색, 팝·확대·흔들림 없음, 짧은 페이드만)은 build.py에 고정이다.
  강조(`em`)는 컷마다 많아야 한 덩이.

## 4. 댓글 카드 2개
- 실제 댓글 2개. 원문을 고치지 않고 그대로, 좋아요 수도 실제 값.
- 선정 기준(사용자 피드백으로 확정):
  1. 20자 미만일 것(이모지 제외). 길면 지나가는 동안 다 읽지 못한다.
  2. 이 영상에서 고른 제품과 관련이 있을 것(제품 이름·사용감·효과·사고 싶다는 반응). 최대한 관련 있는 것을 먼저 고른다.
  3. 그중에서 좋아요를 많이 받은 것.
  제품과 직접 관련된 짧은 댓글이 모자라면, 영상 내용에 공감하는 짧은 댓글 중 좋아요가 많은 것으로 채운다.
- 유튜브 댓글창 모양으로 그리고 프로필 사진과 이름은 모자이크한다.
- 카드는 얼굴을 덮지 않는 위치에(`pos`: top / mid / bottom), 말의 흐름을 방해하지 않는 구간에 4~4.5초
  (2~2.5초는 너무 빨리 지나간다는 피드백을 받았다). 두 카드가 화면에 겹쳐 뜨지 않게 간격을 둔다.
- 이모지는 기본 폰트로 안 그려져서 빠진다(하트는 `"heart": true`로 그릴 수 있다).

## 5. 썸네일 문구와 화면 상단 제목
- 상단 두 줄, 줄당 6자 내외, 윗줄 흰색·아랫줄 노란색.
- 광고처럼 보이지 않게: '추천하는 이거', '필수템/꿀템', '이것', 제품명·브랜드명 금지. 생활 속 상황·장면으로.
  (예: "화장 다 떴을 때 / 덧바르지 마세요")
- 썸네일 문구 + 업로드 제목 조합을 3개 만들어 순위를 매긴다.

## 6. 효과음
5개 정도: 컷 전환 휙(`whoosh`), 팁 시작 팝(`pop`), 핵심 멘트 딩(`ding`), 제품 공개 반짝(`sparkle`).

## 7. 업로드 문구 양식

설명
```
📌 <제품명>
🔗 프로필 인포크 링크에서 '<번호>' 검색

<연예인이 이 제품을 쓰게 된 계기 한 줄>
<영상에서 직접 말한 구체적인 내용 2~3줄, 구어체 "~대요/~다고">
<마무리 한 줄. 예: "…10년을 안 바꿨으면 말 다 했죠.">

#연예인이름 #연예인추천 #브랜드 #제품명 #카테고리추천 … #연예인추천템 #쇼핑쇼츠   (15개 안팎)
```

핀 댓글
```
제품명 : <제품명>
📌 제품 태그 하시거나
📌 프로필 인포크 링크 → '<번호>' 검색하면 바로 나와요. 🔗

<시청자 참여 질문 한 줄>
```

설명 본문에는 원본 영상에서 연예인이 실제로 말한 내용만 쓴다. 지어내지 않는다.
인포크 번호가 없으면 `(번호)`로 비워 두고 알려준다.

## 8. 알아둘 것
- 거울반전·1.1배속·크롭을 해도 저작권 신고나 재사용 콘텐츠 판정을 피할 수 있는 건 아니다.
- 원본이 특정 브랜드의 유료 광고 영상이면 그 사실을 사용자에게 알린다.
- 시청지속 100% 이상은 목표일 뿐 보장할 수 없다.
- 결과 보고는 짧게: 무엇을 만들었는지, 사람이 확인할 것, 차순위 제품 후보.
